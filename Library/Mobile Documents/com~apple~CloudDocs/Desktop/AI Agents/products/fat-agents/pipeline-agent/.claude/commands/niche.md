Help the user select and validate the right niche for their business.

Ask the user for:
1. Their skills/experience (what they're good at)
2. Industries they're considering (2-5 niches)
3. Their offer type (marketing agency, coaching, SaaS, etc.)
4. Their price point target

Load the niche selection reference from references/outreach/niche-selection-fazio.md.

Evaluate each niche against:
- The $15,000 LTV rule
- Economic parameters (market size, willingness to pay, accessibility)
- Fatal mistakes checklist
- Competitive density

Then run a mini-research brief on the top 1-2 niches to validate demand. Use web search to check for active buyers, competitor density, and market signals.

Present the recommendation with clear reasoning. If the user approves a niche, ask if they want to continue to full research (/research) or full pipeline (/pipeline).
