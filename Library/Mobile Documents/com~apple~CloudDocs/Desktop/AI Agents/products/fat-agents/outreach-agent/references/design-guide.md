# Landing Page Design Guide

> Comprehensive design system extracted from 30+ high-converting landing pages in the swipe file.
> Use this as the design reference when building any landing page.

---

## Color Palettes by Niche

Pick the palette that matches the client's niche. When in doubt, default to dark + purple (the most common pattern).

### Trading / Finance / Forex
- **Background:** #000, #0f0f0f, #05071a (dark navy)
- **Primary accent:** Gold (#eecb07, #d4af37, #a88647, #efbf04)
- **Secondary accent:** Purple (#8b00ff, #bd38e6)
- **Text:** White #fff, light gray #a6a6a6
- **Feel:** Luxury, exclusivity, wealth signaling
- **References:** The Kingdom (MambaFx), Forex Platinum Trading, Vantage Education

### Marketing / Agency / Consulting
- **Background:** #000, #0a0a0a, #0d0d0d
- **Primary accent:** Purple (#7803ff, #884bfa, #7c3aed, #bd38e6)
- **Secondary accent:** Blue (#1a8eed, #0369cb), Green (#34d399)
- **Text:** White #fff, gray #cbd5e1
- **Feel:** Modern, authoritative, tech-forward
- **References:** Client Ascension, Infinia Growth, Sell More Online, GMB Builder, Clavicular

### E-commerce / Brand / Apparel
- **Background:** #000, #0a0a0a
- **Primary accent:** Red/neon (#ff1f3d, #e31c25, #ff2441)
- **Secondary accent:** Gold for premium, neon for streetwear
- **Text:** White #fff
- **Feel:** Bold, urgent, high-energy
- **References:** Marshal Crews, Cobrax Creative, Caprice Tour

### SaaS / Tech / AI
- **Background:** #000, #0d0d0d
- **Primary accent:** Blue (#0369cb, #2e54ff, #3a96f2, #2980b9)
- **Secondary accent:** Cyan (#32cae7, #22d3f2, #05a1d4), Green (#0cad2d)
- **Text:** White #fff, light gray
- **Feel:** Clean, trustworthy, innovative
- **References:** Crayo AI, The Stickley Method, The Scale Club, The Grid, Novify Media

### Female Audience / Lifestyle / Coaching
- **Background:** White, #fff6f9 (light pink tint), soft gradients
- **Primary accent:** Pink/magenta (#fb96bc, #ff9ebb, #d8959b)
- **Secondary accent:** Purple (#bd38e6, #6127f3)
- **Text:** Dark #060d0b, #0a0a0a
- **Feel:** Warm, aspirational, empowering
- **References:** Becoming Her, She Sells Remote

### Creator Economy / Education / Courses
- **Background:** #000 or white-to-gray gradient (varies)
- **Primary accent:** Blue (#2e54ff, #4088ff), Orange (for warmth)
- **Secondary accent:** Purple (#673AE4)
- **Text:** Context-dependent
- **Feel:** Approachable, results-driven, aspirational
- **References:** The Creator Blueprint, Kayla Parrilla, Brand Scaling (Brez)

### Standout / Differentiation Colors
When the niche is saturated with dark+purple, consider these to stand out:
- **Lime green on dark:** #42CE09 (Razza) — fresh, energetic
- **Orange/amber on dark:** #ff9e36, #ffbf00 (Brand Scaling Bootcamp) — warm, bold
- **Cyan/turquoise on light:** #32cae7, #22d3f2 (The Stickley Method) — tech, clean
- **Light theme overall:** #f2f5fd (Novify Media) — breaks pattern, clean SaaS feel
- **Ultra-dark purple base:** #0f001f (Puppetsmaster) — deeper than black, mysterious

## Typography System

### Headline Fonts (Pick One)

**Serif (premium/authority feel):**
- Playfair Display — classic luxury, weight 700-800
- Instrument Serif — modern editorial
- Petrona — warm serif option

**Geometric Sans (modern/bold feel):**
- Syne — geometric, strong personality
- Space Grotesk — clean geometric
- Clash Display — bold, contemporary
- Integral CF — ultra-bold, impact
- Sora — rounded geometric

**Specialty:**
- Audiowide — tech/futuristic
- Oregano — handwritten/personal accent

### Body Fonts (Pick One)

In order of frequency in the swipe file:
1. **Inter** — most used across all pages (near-universal)
2. **DM Sans** — clean, slightly rounded
3. **Plus Jakarta Sans** — modern, versatile
4. **Poppins** — geometric, friendly
5. **Montserrat** — classic, slightly wider

### Recommended Pairings

| Niche | Headline | Body |
|-------|----------|------|
| Trading/Finance | Playfair Display 700 | Inter 400 |
| Agency/Marketing | Syne 700 or Space Grotesk 700 | Inter 400 or DM Sans 400 |
| E-commerce | Clash Display 800 or Integral CF 800 | Plus Jakarta Sans 400 |
| SaaS/Tech | Sora 700 or Inter Display 700 | Inter 400 |
| Female/Lifestyle | Clash Display 600 or Playfair Display 700 | Poppins 400 |
| Creator/Education | Space Grotesk 700 | Inter 400 or DM Sans 400 |

### Font Sizing

| Element | Desktop | Tablet | Mobile |
|---------|---------|--------|--------|
| Hero headline | 48-72px | 36-48px | 28-36px |
| Section heading | 32-40px | 28-32px | 24-28px |
| Subheadline | 20-24px | 18-20px | 16-18px |
| Body text | 16-18px | 16px | 15-16px |
| CTA button text | 16-20px | 16px | 14-16px |
| Caption/meta | 13-14px | 12-13px | 12px |

### Font Weights

- Hero headline: 700-800 (bold/extrabold)
- Section headings: 600-700 (semibold/bold)
- Body: 300-400 (light/regular)
- CTA text: 600-700 (semibold/bold)
- The contrast between heavy headlines and light body is critical

## Layout System

### Page Container
- **Max-width:** 1200-1440px (most common: 1200px)
- **Centering:** margin: 0 auto
- **Side padding:** 20-40px (mobile), 40-80px (tablet), 80-120px (desktop)

### Section Spacing
- **Between major sections:** 60-100px (desktop), 40-60px (mobile)
- **Between sub-sections:** 24-40px
- **Between elements within a section:** 16-24px

### Responsive Breakpoints
- **Mobile:** up to 809px
- **Tablet:** 810px - 1199px (or 1439px on some pages)
- **Desktop:** 1200px+ (or 1440px+)

### Grid Systems
- **Feature/benefit cards:** 2-3 columns on desktop, 1 column mobile
- **Testimonials:** 2-3 column grid or horizontal carousel
- **Client logos:** 4-6 per row, scrolling or static
- **Pricing tiers:** 2-4 columns, side by side

## Component Library

### Hero Section
- Full-width or contained (max-width)
- Centered text alignment (most common) or left-aligned with right image/video
- Background: solid dark, gradient overlay, or subtle radial gradient
- Video player: sticky positioning on some pages (Sell More Online)
- Height: usually 80-100vh on desktop

### CTA Buttons
**Primary (main action):**
- Gradient background matching accent color
- Border-radius: 10-20px (rounded) or 1000px (full pill)
- Padding: 16-20px vertical, 32-48px horizontal
- Font weight: 600-700
- Optional: subtle animation (2s infinite bounce/pulse)
- Text: UPPERCASE on some pages, Title Case on others

**Secondary (supporting action):**
- Outlined or ghost button (transparent bg, border matching accent)
- Same border-radius as primary
- Less visual weight

**Below every CTA, add friction reducers:**
> "$199 once. Join 2,600+ marketers. 2 minutes to install."

Formula: [Price/risk reversal] + [Social proof number] + [Speed/ease]

### Cards
**Glassmorphic card:**
- Background: rgba(255, 255, 255, 0.05) to rgba(255, 255, 255, 0.1)
- Backdrop-filter: blur(5-8px)
- Border: 1px solid rgba(255, 255, 255, 0.1)
- Border-radius: 24-39px
- Padding: 24-40px

**Bordered dark card:**
- Background: #111, #1a1a1a, or #1c1c21
- Border: 1px solid rgba(255, 255, 255, 0.1)
- Border-radius: 16-24px
- Padding: 24-32px

**Feature card with icon:**
- Icon container: 44-68px, rounded (full circle or rounded square)
- Icon color: accent color
- Title: font-weight 600, 18-20px
- Description: font-weight 400, 14-16px, lighter gray text

### Testimonial Cards
- Profile image: circular (border-radius: 400px or 50%), 40-68px diameter
- Name: white, font-weight 500-600
- Role/company: lighter gray, font-weight 400
- Quote: 14-16px, slightly indented or with quote marks
- Star ratings (optional): gold stars inline

### Client Logo Bar
- 6-10 logos
- Grayscale or muted (not full color — keeps page cohesive)
- Horizontal scroll or static grid
- Height: 40-60px per logo
- Spacing: 40-80px between logos

### Pricing Tier Cards
- 2-4 tiers side by side
- Highlighted/recommended tier: accent border or "POPULAR" badge
- Each tier: name, price, feature list with checkmarks
- CTA button in each tier
- Comparison checkmarks: ✓ (included) / — (not included)

### Navigation
- Fixed/sticky header, 60-80px height
- Transparent or dark background with blur
- Logo left, nav items center or right
- CTA button in nav (accent color)
- Mobile: hamburger menu

## Visual Effects

### Gradients
- **Radial gradient backgrounds:** Subtle color glow from center or corner
  - Example: `radial-gradient(circle at 50% 0%, #7803ff33 0%, #000 70%)`
- **Linear gradient CTAs:** Accent color → slightly different shade
  - Example: `linear-gradient(135deg, #7803ff, #5a00cc)`
- **Text gradients (sparingly):** On hero headlines for emphasis

### Shadows & Glow
- **Card shadows:** `0 0 42px rgba(0, 0, 0, 0.6)` (subtle depth)
- **CTA glow:** `0 0 16-90px [accent color with low opacity]`
- **Text shadow:** On hero text over images: `0 2px 4px rgba(0, 0, 0, 0.5)`

### Blur Effects
- **Backdrop blur on cards:** blur(5-8px) — creates glassmorphism
- **Background blur on nav:** blur(10-20px) — semi-transparent sticky nav
- **Decorative blur circles:** Large blurred colored circles in background

### Animations (Subtle)
- **CTA bounce:** 2s infinite ease-in-out, 3-5px vertical movement
- **Fade-in on scroll:** Sections fade in as user scrolls
- **Logo carousel:** Smooth horizontal scroll for client logos
- **Hover states:** Slight scale (1.02-1.05) or brightness shift on cards

## Mobile Optimization

- **Stack everything vertical** — no side-by-side on mobile
- **CTA buttons full-width** on mobile
- **Reduce hero headline** from 72px → 28-36px
- **Reduce section spacing** from 80px → 40-60px
- **Sticky CTA bar** at bottom of screen on mobile (optional but effective)
- **Testimonials as vertical stack** instead of grid
- **Pricing tiers as swipeable carousel** instead of side-by-side
- **Touch targets minimum 44px** height for all interactive elements

## Quick Design Checklist

Before shipping a landing page design:

- [ ] Dark background or appropriate niche color palette applied
- [ ] Accent color consistent throughout (CTAs, highlights, icons)
- [ ] Headline font ≠ body font (weight and/or family contrast)
- [ ] Hero section has clear visual hierarchy (headline > subheadline > CTA)
- [ ] CTA buttons use gradient accent, not flat gray
- [ ] Friction reducer text below every CTA
- [ ] Cards use glassmorphism or bordered dark treatment
- [ ] Social proof is specific (numbers, not "many customers")
- [ ] Mobile breakpoints tested (810px, 390px)
- [ ] Page loads fast (optimize images, minimize animations)
- [ ] No more than 2-3 fonts loaded
- [ ] Consistent spacing system (multiples of 8px)
